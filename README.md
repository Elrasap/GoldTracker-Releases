# GoldTracker – Kompatibilität für alte Android-Versionen

Dieses öffentliche Repository stellt ausschließlich das Update-Manifest für frühe GoldTracker-Installationen bereit. Die Adresse ist in diesen Apps fest eingebaut und darf nicht gelöscht, umbenannt oder privat geschaltet werden.

`latest.json` bietet das signierte Übergangsupdate **1.0.1381** an. Nach dessen Installation beziehen Apps weitere Updates direkt von `https://updates.elrasap-goldtracker.online/latest.json`.

Der APK-Download erfolgt über den GoldTracker-Update-Server. Quellcode, Zugangsdaten und Signierschlüssel sind nicht Bestandteil dieses Repositorys. Die bestehende App für ein Update nicht deinstallieren.
